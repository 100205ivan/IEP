## 微笑核對與關閉

兩款準備頁先顯示中性表情；在使用者確認露齒微笑期間，同步等待即時預覽出現「開心樣態」，兩款均觀察到變化。準備階段資料沒有加入上述正式分類次數。CPT 正式 134 次皆為中性，使用者確認微笑只發生於準備階段，所以正式統計本身不能用來驗證微笑反應。

結束及手動關閉後，預覽隱藏、暫停；CPT 結果及最後關閉觀察到 `readyState=0`、影像尺寸為零。唯讀瀏覽器介面不暴露 `srcObject`，因此沒有宣稱由該介面直接讀取硬體串流狀態。串流及 worker 的清理另有生命週期單元檢查。

## 保存範圍

正式遊戲結果要透過「匯入 IEP 評量紀錄 → 確認匯入」寫入 MariaDB，檔案匯出與準備頁預覽不會建立系統紀錄。本次測試的完整逐題原始結果沒有保存，後續僅以兩筆清楚標示「功能測試／非學生能力評量」的人工紀錄補登現有統計，並核對 API 讀回與頁面重新整理後仍可查看。未重建或冒充完整遊戲成績。

本機資料庫補登內容、識別碼、備份與原始截圖保留在本機測試資料，未隨 Git 提交。開發者取得程式碼後會取得偵測與保存功能，不會因此取得其他電腦上的測試紀錄。
